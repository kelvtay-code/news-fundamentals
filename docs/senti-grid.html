Read this before trading off it

A senti score reads the headlines, nothing else. It is not a Wyckoff phase, a GEX read or a risk gate, and a score of 8 says a catalyst exists, not that the structure supports an entry. Run it through voltbuster and riskcheck before it becomes a position.
